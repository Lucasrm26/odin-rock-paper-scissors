A console-based Rock, Paper, Scissors game built to practice the core fundamentals of JavaScript. Developed as part of **The Odin Project** curriculum.

## 💡 Key Learnings

- Applying a problem-solving and logical approach before writing code.
- Structuring algorithms using pseudocode.
- Using browser DevTools for debugging.
- Working with JavaScript functions, `for` loops, and conditional statements.

## 🛠️ Built With

- **HTML5**
- **JavaScript (ES6+)**

## 🎮 How to Play

Since this version runs entirely in the browser console:
1. Open the `index.html` file in your browser.
2. Open the browser's **Developer Tools** (`F12` or `Ctrl + Shift + I` / `Cmd + Option + I`) and switch to the **Console** tab.
3. Follow the on-screen prompts to play a 5-round match against the computer.
